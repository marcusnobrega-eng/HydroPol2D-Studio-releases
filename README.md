# HydroPol2D Studio

HydroPol2D Studio is a desktop app for flood and water-quality modeling with HydroPol2D. You set up a case on a map, run the model on your own computer and look at the results.

This page holds only the installers. It does not hold the source code.

## Download

Get the latest version under **[Releases](../../releases)**.

| Computer | File |
|---|---|
| Mac with Apple Silicon (M1 or newer) | `HydroPol2D-Studio-macOS-arm64.zip` |
| Windows (64-bit) | `HydroPol2D-Studio-Windows-x64.zip` |

You need about 1.5 GB of free disk space.

## Install

See **[INSTALL.md](INSTALL.md)**. In short: unzip, open the app, paste your license code.
